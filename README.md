# GAS-IMS — PSG-포항충전소 생산관리 시스템

`index.html` 한 파일로 돌아가는 가스 재고·생산·출고 관리 시스템입니다.
데이터는 Firebase Firestore에 저장되고, localStorage에 항상 복사본이 남습니다.

배포 주소: **https://Kor-Sangyeoniii.github.io/gas-ims/**

---

## 📱 아이폰에서 앱처럼 쓰기

### 1. 홈 화면에 추가

1. 아이폰 **사파리**로 https://Kor-Sangyeoniii.github.io/gas-ims/ 접속
   *(크롬·네이버앱 등 다른 브라우저는 홈 화면 추가가 제대로 동작하지 않습니다. 반드시 사파리)*
2. 하단 **공유 버튼(⬆︎)** → **홈 화면에 추가** → **추가**
3. 홈 화면에 `GAS-IMS` 아이콘이 생깁니다

이 아이콘으로 실행하면 주소창 없이 전체화면으로 뜨고, 전용 기동 화면(스플래시)이 나옵니다.

> **중요**: 알림과 완전한 오프라인 동작은 **홈 화면 아이콘으로 실행할 때만** 됩니다.
> 사파리 탭에서 열면 iOS가 웹 푸시를 허용하지 않습니다. (iOS 16.4 이상 필요)

### 2. 화면 구성

폭 768px 이하(= 아이폰 전부)에서는 자동으로 모바일 화면으로 바뀝니다.

| | |
|---|---|
| 하단 탭바 | 현황 · 생산 · 출고 · 이력 · 더보기 |
| 더보기 | 나머지 전체 메뉴(기초재고·카트리지·공병입고·발주·분석·마감·관리자) |
| 입력창 | 16px로 고정 — 탭할 때 화면이 확대되지 않습니다 |
| 버튼 | 최소 44px — 장갑 끼고도 눌립니다 |
| 노치/홈바 | safe-area 처리 완료 |

### 3. 홈 화면 아이콘 길게 누르기

`일일 생산 입력` / `출고` / `대시보드` 로 바로 갈 수 있는 바로가기가 뜹니다.

## 📶 오프라인 동작

지하·창고처럼 신호가 약한 곳에서도 쓸 수 있습니다.

- 한 번 접속해 두면 앱 본체가 기기에 저장되어 **비행기 모드에서도 실행**됩니다
- 오프라인 중 입력한 내용은 기기에 저장되고, 헤더에 `↻ 전송 대기 N` 배지가 뜹니다
- 신호가 돌아오면 **자동으로 서버에 밀어 넣고** 배지가 사라집니다
- 서버 응답이 없어도 로컬에 저장해 둔 데이터를 그대로 보여줍니다 (예전엔 이 상황에서 화면이 멈추거나 로컬 데이터가 비워졌습니다)

수동으로 밀어 넣고 싶으면 앱을 껐다 켜거나, 개발자 콘솔에서 `flushOutbox()` 를 호출하면 됩니다.

## 🔔 알림 설정

`관리자` 탭 → `📱 모바일 앱 · 알림 설정`

### 서버 없이 되는 것 (설정만 하면 끝)

- **재고 부족 배너** — 대시보드 상단에 부족 품목이 표시됩니다
- **앱이 켜져 있을 때의 알림** — 다른 기기에서 재고가 바뀌어 기준 밑으로 떨어지면 알림이 뜹니다

기준값 두 개만 정하면 됩니다.

| 항목 | 기본값 | 의미 |
|---|---|---|
| 실병 부족 기준 | 5개 이하 | 품목·규격·업체별 실병 수량 |
| He 부족 기준 | 50kg 이하 | ISO Tank + 카트리지 합산 |

### 앱을 닫아둔 상태에서도 받으려면 (선택)

아이폰에서 백그라운드 푸시를 받으려면 **VAPID 키 등록 + 서버 배포** 두 가지가 필요합니다.

#### ① VAPID 공개키 등록

1. [Firebase 콘솔](https://console.firebase.google.com/) → `psg-ph-product-management` 프로젝트
2. ⚙️ **프로젝트 설정** → **클라우드 메시징** 탭
3. **웹 푸시 인증서** → 키 쌍이 없으면 `키 쌍 생성`
4. 표시된 키(`B...`로 시작하는 긴 문자열)를 복사
5. 앱 → 관리자 → 알림 설정 → **VAPID 공개키** 칸에 붙여넣고 `💾 설정 저장`
6. 각 아이폰에서 **`🔔 이 기기에서 알림 받기`** 를 누르고 권한 허용

여기까지만 해도 **앱이 켜져 있는 동안**은 푸시가 옵니다.

#### ② 발송 서버 배포

`push-server/` 폴더에 Cloud Function이 들어 있습니다. 30분마다 재고를 점검해서
등록된 기기 전부에 알림을 보냅니다.

```bash
npm install -g firebase-tools
firebase login
firebase init functions      # 기존 프로젝트 선택 → JavaScript → 기존 파일 덮어쓰지 않기

# push-server/index.js, package.json 을 functions/ 로 복사한 뒤
cd functions && npm install
firebase deploy --only functions
```

배포 후 확인:

```bash
curl https://asia-northeast3-psg-ph-product-management.cloudfunctions.net/checkStockNow
# → {"sent":2,"failed":0,"pruned":0} 같은 응답
```

> Cloud Functions는 Firebase **Blaze(종량제)** 요금제가 필요합니다.
> 30분에 한 번 호출이면 실사용 요금은 사실상 0원이지만, 카드 등록은 해야 합니다.
> 부담스러우면 ①까지만 하고 "앱 켜져 있을 때 알림"으로 쓰셔도 됩니다.

### 알림이 안 올 때

| 증상 | 확인할 것 |
|---|---|
| `🔔` 버튼이 회색이고 경고문이 뜸 | 사파리 탭에서 열었는지 확인 → 홈 화면 아이콘으로 실행 |
| 권한 요청 창이 안 뜸 | 설정 → GAS-IMS → 알림 → 허용 |
| 토큰 발급 실패 | VAPID 키가 이 Firebase 프로젝트 것인지 확인 |
| 앱 닫으면 안 옴 | `push-server` 배포 필요 (위 ②) |

## 🗂 파일 구성

```
index.html          앱 본체 (단일 파일)
uploader.html       index.html 을 GitHub에 올리는 배포 도구
manifest.json       PWA 매니페스트 (앱 이름·아이콘·바로가기)
sw.js               서비스워커 (오프라인 캐시 + 푸시 수신)
icons/              앱 아이콘 + 기동 화면 22종
tools/gen-icons.py  아이콘·기동화면 생성 스크립트
push-server/        재고 부족 푸시 발송 Cloud Function (선택)
```

### `uploader.html` 로 배포할 때 주의

업로더는 **`index.html` 하나만** 덮어씁니다.
`manifest.json` · `sw.js` · `icons/` 는 저장소에 이미 올라가 있어야 하며, 한 번 올려두면 다시 건드릴 일이 없습니다.

⚠️ 업로드하기 전에 **GitHub에서 최신 `index.html`을 내려받아** 편집하세요.
예전 버전을 올리면 모바일·오프라인·알림 기능이 통째로 사라집니다.

### 아이콘을 다시 만들려면

```bash
pip install pillow
python3 tools/gen-icons.py
```

`sw.js` 를 수정했다면 파일 안의 `VERSION` 값을 올려야 기존 기기의 캐시가 갱신됩니다.

## ⚠️ 보안 관련 참고

이 앱은 Firebase API 키를 클라이언트에 그대로 담고, Firestore에 인증 없이 읽기·쓰기를 합니다.
즉 **주소를 아는 사람은 누구나 데이터를 읽고 고칠 수 있습니다.** (앱 안의 로그인 화면은 화면 표시용일 뿐, 서버를 지켜주지 않습니다.)

이번 작업에서 바꾸지 않았지만, 사내 데이터가 들어가는 만큼 정리해 두시는 게 좋습니다.

- Firebase Authentication(익명 로그인이라도) + Firestore 보안 규칙으로 접근 제한
- 알림 토큰(`gasims_push_tokens_v1`)도 같은 컬렉션에 있으므로 함께 보호됩니다
